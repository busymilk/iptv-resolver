# IPTV 智能域名解析与自动更新微服务 (DoH & 测速重排 & Web后台 & 滚动日志)

这是一套轻量级、高并发的 IPTV 节目源自动网络抓取、**DoH 加密域名解析、IP 优选连接测速、同名源网速重排序、局域网 Web 共享、滚动日志归档与可视化管理后台**于一体的自包含微服务。

本服务旨在解决 IPTV 域名解析和播放中的核心痛点，提供一站式、企业级的 DevOps 自动化拉流选线方案：
1. **防本地代理 Fake-IP 污染**：集成 DoH (DNS-over-HTTPS) 引擎，100% 避开本地 Clash / 代理客户端对传统 DNS 的 Fake-IP 劫持，确保解析出真实的公网 IP（使导出的列表能分发到家庭电视等其他设备正常播放）。
2. **双层 IP 优选与连接测速**：
   - **第一层 (域名级)**：当一个域名解析出多个公网 CDN 地址时，脚本会在本地发起多线程高并发 TCP 握手测速，挑选出**连接响应延迟最低、最稳定**的那个 IP 替换入播放 URL。
   - **第二层 (源级别)**：当订阅源中**同一个名字的电视台存在多个不同的视频源链接**（例如连续出现多个同名的 `CCTV-1`）时，系统会自动进行**同名聚合**，在所有链接完成首轮 IP 解析 and 测速后，**根据它们的延迟耗时（秒）进行升序重排序（速度最快最稳定的链接排在最前面）**。这保证了播放器在加载时秒开首选，并能按网速顺次备用切换！
3. **极简局域网电视分发**：内置多线程高性能 HTTP 共享服务器。无需额外配置 Nginx 或 Caddy，容器一键启动即可直接向家庭局域网广播解析后的播放列表，您的电视机、Kodi、DIYP 播放器可一键订阅！
4. **可视化 Web 管理后台**：内置 Web 配置管理控制台（Web GUI）。在浏览器打开 `http://<服务器IP>:<端口>/` 即可直观管理全局策略、高并发测速，并可**动态增、删、改每一个网络抓取源**。界面中**新增展示了上次解析成功时间与预计下次更新时间**，并在底部**直接嵌入了高颜值、自动滚屏的实时系统日志终端视窗**，支持异步秒级开机，体验惊艳！
5. **滚动日志归档与局域网一键监控**：
   - 引入工业级日志滚存机制。日志会同步追写并归档在 `/output/resolver.log` 中。
   - **防爆盘自动滚动**：单日志文件限制最大 **2MB**，自动轮转并最多保留 **3 个历史日志备份文件**，100% 避免撑爆您的硬盘。
   - **双重监控选择**：既支持在局域网内任意浏览器输入 `http://<您的服务器IP>:<端口>/output/resolver.log` 直接在线查看，也支持在配置后台 GUI 面板的最下方通过等宽终端视窗实现一键无感运维可视化！

## 🚀 项目特色
- **云端免编译拉取即用**：项目集成了 GitHub Actions 自动化构建，您在部署时**无需下载源码或在本地编译 Docker 镜像**，直接拉取即可一键秒级启动。
- **同名电视多源网速重排序**：多源智能同名聚合，测速后从小到大升序重排，最快最稳的播放链接自动置顶！
- **可视化 Web 管理控制台**：精美玻璃拟态亮白高透设计。支持可视化管理订阅源，动态增删改，一键保存热重载，支持开机异步加载与一键流光更新。
- **实时 GUI 日志终端视窗 (New!)**：管理后台底部直连运行日志并支持 3 秒自动轮转刷屏，无需手动打 docker logs 即可直观掌控测速排序细节。
- **工业级滚动日志防爆盘**：本地文件滚动归档，限制 2MB 并保留最近 3 份，防撑爆硬盘。
- **数据源层级精细化策略 (New!)**：支持为每个数据源单独配置解析模式。例如：可强制指定某个源 `"mode": "ipv6-only"` 或 `"mode": "ipv4-only"`，一旦该源的域名解析不到该特定协议的 IP，**直接将该条目忽略/过滤**，不再尝试降级备用，实现绝对纯净的单协议源过滤。
- **内置局域网 Web 共享服务**：微服务内置了多线程 HTTP Server（缺省默认 8080 端口，可通过 `web_port` 自定义端口）。电视端输入 `http://<服务器IP>:<端口>/output/<文件名>` 即可直接订阅更新。
- **超强并发性能**：多线程高并发解析与 TCP 连接测速，**190 个连接的解析、测速与优选可在 15 秒内全部搞定**！
- **定时更新守护**：内置定时循环更新服务。只需一次部署，即可设定更新频率，作为后台守护进程实时维护。
- **智能链接识别**：内置 GitHub URL 翻译器。如果填入 GitHub 网页端订阅链接，脚本会自动翻译成 Raw 纯文本订阅链接进行抓取。
- **死链自动剔除**：在测速模式下，若某域名所有 IP 均彻底不可达（且开启了过滤策略），该频道会被自动过滤，确保生成的播放列表 100% 极速可用。

## 📂 项目结构
```text
├── config.json          # 核心配置文件（DNS/更新周期/数据源列表/局域网共享端口）
├── config_readme.md     # 配置文件详尽使用指南
├── index.html           # 微服务内置的可视化配置管理后台 (Web GUI)
├── iptv_resolver.py     # 核心 Python 解析、测速、重排序与 Web API 共享服务脚本
├── Dockerfile           # 轻量化 Docker 容器构建描述文件 (Alpine, ~35MB)
├── docker-compose.yml   # Docker Compose 一键启动配置文件
├── README.md            # 项目主页说明文档
└── output/
    ├── best_sorted_resolved.m3u  # 优选测速重排序后的播放列表输出文件
    └── resolver.log              # 本地自动滚动轮转运行日志文件 (最大2MB,保留3份)
```

## 🐳 Docker Compose 一键部署

在您需要运行服务的机器上（如群晖 NAS、软路由、VPS ），**您甚至不需要拷贝项目源码**，只需在该机器的新建文件夹中，放入您的 `config.json` 和 `docker-compose.yml` 两个文件，直接执行以下极简启动命令即可：

```bash
# 1. 直接拉取云端专属最新镜像并启动容器
docker compose up -d

# 2. 实时查看容器的运行日志（也可通过局域网直接在浏览器输入地址监控）
docker compose logs -f
```

**电视/播放器局域网订阅、后台访问与在线日志监控地址**：
假如您运行该 Docker 容器的服务器（如群晖 NAS、软路由）的局域网 IP 是 `192.168.31.5`：

## 🛠️ 本地手动运行

如果您不想使用 Docker，也可直接通过 Python 3 手动运行该工具（脚本内置了依赖自动补齐机制，自动安装 `requests` 和 `dnspython`）：

```bash
# 执行单次解析测试
python3 iptv_resolver.py -c config.json
```
*(注：手动运行时，若没有显式设置 "web_port": 0，程序在单次执行后会默认以 8080 端口继续常驻主线程以提供 Web 局域网分发及后台管理服务)*
